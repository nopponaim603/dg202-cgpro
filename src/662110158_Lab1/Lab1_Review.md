## 🏛️ ส่วนที่ 1: โครงสร้างโปรแกรมและ Animation พื้นฐาน (Lab1_1)
แล็บนี้สาธิตโปรแกรมกล่องสี่เหลี่ยมสีแดงกระเด้งไปมาบนหน้าต่างสีน้ำเงิน (Bounce) ซึ่งแสดงโครงสร้างหลักของ OpenGL/GLUT:

### 1. โครงสร้างฟังก์ชันหลัก (main)
ทำหน้าที่ตั้งค่าหน้าต่างการแสดงผล และลงทะเบียน Callback Functions:
* **`glutInitDisplayMode(GLUT_DOUBLE | GLUT_RGB)`**: ตั้งค่าโหมดการแสดงผลให้ใช้ **Double Buffering** (ป้องกันการกะพริบของหน้าจอโดยใช้บัฟเฟอร์สองตัวสลับกันแสดงผล) และใช้โหมดสีแบบ RGB
* **`glutCreateWindow("Bounce")`**: สร้างหน้าต่างแสดงผล
* **`glutDisplayFunc(RenderScene)`**: ลงทะเบียน Callback สำหรับวาดภาพหน้าจอ
* **`glutReshapeFunc(ChangeSize)`**: ลงทะเบียน Callback เมื่อขนาดหน้าต่างเปลี่ยน
* **`glutTimerFunc(33, TimerFunction, 1)`**: ตั้งเวลาเพื่อเรียกทำงานฟังก์ชันอื่นในอนาคต (ในที่นี้ใช้ทำ Animation ทุกๆ 33 มิลลิวินาที ~ ประมาณ 30 FPS)
* **`glutMainLoop()`**: เริ่มต้นลูปหลักการทำงานของ GLUT (ไม่หลุดจากฟังก์ชันนี้จนกว่าจะปิดโปรแกรม)

### 2. การจัดการขนาดหน้าต่าง (Viewport & Orthographic Projection)
ในฟังก์ชัน `ChangeSize(GLsizei w, GLsizei h)`:
* **`glViewport(0, 0, w, h)`**: กำหนดขอบเขตของการแสดงผลภาพจริงบนพิกเซลหน้าจอ
* **`glMatrixMode(GL_PROJECTION)` & `glLoadIdentity()`**: รีเซ็ตและเลือกโหมดการฉายแสง (Projection)
* **`glOrtho(...)`**: กำหนดพิกัดโลกสองมิติแบบตั้งฉาก (Orthographic) ช่วยควบคุมไม่ให้วัตถุเบี้ยวเมื่อสัดส่วนหน้าต่างเปลี่ยนไป (Aspect Ratio) โดยล็อคให้ขนาดหน้าต่างที่แคบที่สุดมีระยะอย่างน้อย -100 ถึง 100 

### 3. การวาดและการทำภาพเคลื่อนไหว
* ใน `RenderScene`:
  * **`glClear(GL_COLOR_BUFFER_BIT)`**: ล้างหน้าจอด้วยสีพื้นหลังที่กำหนดไว้ใน `SetupRC` (`glClearColor`)
  * **`glColor3f(1.0f, 0.0f, 0.0f)`**: กำหนดสีวาดภาพเป็น สีแดง
  * **`glRectf(x1, y1, x1 + rsize, y1 - rsize)`**: วาดรูปสี่เหลี่ยมผืนผ้าทึบตามพิกัดมุมซ้ายบนและขวาล่าง
  * **`glutSwapBuffers()`**: สลับบัฟเฟอร์แสดงผลหน้าจอ (ใช้ใน Double Buffering)
* ใน `TimerFunction`:
  * คำนวณขอบเขตเพื่อตรวจสอบการชนขอบหน้าต่าง หากชนจะกลับทิศทางการเคลื่อนที่ (`xstep = -xstep`, `ystep = -ystep`)
  * เรียกใช้ **`glutPostRedisplay()`** เพื่อสั่งให้ระบบทำการวาดฉากใหม่
  * เรียกตนเองแบบ Recursive เพื่อวนลูปเวลาถัดไป: `glutTimerFunc(33, TimerFunction, 1)`

## 🖌️ ส่วนที่ 2: การวาดรูปทรงเรขาคณิตพื้นฐาน (Lab1_2 & Lab1_3)
การวาดวัตถุสองมิติ/สามมิติใน OpenGL จะเริ่มต้นด้วยการเรียก `glBegin(โหมดรูปทรง)` และสิ้นสุดด้วยคำสั่ง `glEnd()` เสมอ

### 1. โหมดรูปทรงเรขาคณิต (Primitives) ที่ใช้ในแล็บนี้
* **`GL_POINTS`** (Lab1_2):
  * วาดจุดแยกแต่ละพิกัดเป็นจุดๆ อิสระ
  * กำหนดขนาดจุดด้วย **`glPointSize(ขนาด)`**
* **`GL_LINES`** (Lab1_3_1):
  * วาดเส้นตรงเชื่อมต่อกันทีละคู่พิกเซล (เช่น ใส่พิกัด 4 จุด จะได้เส้นตรง 2 เส้นที่ไม่เกี่ยวข้องกัน)
* **`GL_LINE_STRIP`** (Lab1_3_2):
  * วาดเส้นตรงเชื่อมต่อเนื่องกันไปเรื่อยๆ (จุดแรกเชื่อมจุดสอง, จุดสองเชื่อมจุดสาม...) แต่จุดสุดท้ายจะไม่เชื่อมกลับมาจุดแรก
* **`GL_LINE_LOOP`** (Lab1_3_2 & Lab1_3_4):
  * ทำงานเหมือน `GL_LINE_STRIP` แต่จะเชื่อมต่อจุดสุดท้ายกลับมาที่จุดเริ่มต้นโดยอัตโนมัติ (ได้วงปิดรูปปิด)
* **`GL_TRIANGLES`** (Lab1_3_3):
  * วาดรูปสามเหลี่ยมอิสระ โดยทุกๆ 3 จุดพิกัดจะถูกรวมกันเป็นรูปสามเหลี่ยม 1 รูป

### 2. การสร้างเส้นปรุและเปลี่ยนขนาดเส้น (Lab1_3_4)
* **`glLineWidth(ขนาด)`**: กำหนดขนาดความหนาของเส้น
* **`glEnable(GL_LINE_STIPPLE)`**: เปิดใช้งานฟังก์ชันเส้นปะ/เส้นสไตล์กำหนดเอง
* **`glLineStipple(factor, pattern)`**:
  * `pattern` (เลขฐานสิบหก): รูปแบบบิตที่ใช้แสดงเส้นตรงสลับเว้นว่าง เช่น `0x5555` (บิตสลับ 0101010101010101)
  * `factor`: ตัวคูณระยะการยืดของบิตแพทเทิร์น (เช่น factor = 3 แปลว่า 1 บิตในแพทเทิร์นจะมีผลกว้างยาวขึ้นเป็น 3 เท่า)

## 📖 สรุปคำสั่งสำคัญ (OpenGL/GLUT API Cheat Sheet)

| คำสั่ง (API) | หน้าที่การทำงาน |
| :--- | :--- |
| `glutInitDisplayMode(...)` | กำหนดโหมดการแสดงผล (เช่น สีแบบ RGB, บัฟเฟอร์ Double หรือ Single) |
| `glViewport(x, y, w, h)` | กำหนดขนาดสเกลพิกเซลพื้นที่แสดงผลบนหน้าจอโปรแกรม |
| `glOrtho(left, right, bottom, top, near, far)` | กำหนดระบบพิกัดกล้องแบบขนานฉายตั้งฉาก (Orthographic) |
| `glClearColor(r, g, b, a)` | กำหนดสีพื้นหลังที่จะใช้ล้างจอภาพ |
| `glColor3f(r, g, b)` | กำหนดสีปัจจุบันที่จะใช้สำหรับวาดรูปทรงถัดไป |
| `glRectf(x1, y1, x2, y2)` | วาดสี่เหลี่ยมผืนผ้าแบบทึบ |
| `glPointSize(size)` | กำหนดความกว้างของจุดเรขาคณิต |
| `glLineWidth(width)` | กำหนดความหนาของเส้นตรง |
| `glEnable(GL_LINE_STIPPLE)` | เปิดใช้งานระบบแต่งเส้นปะ |
| `glLineStipple(factor, pattern)` | กำหนดลักษณะ/ลวดลายของเส้นปะ |
| `glutPostRedisplay()` | แจ้งเตือนระบบให้สั่งรันฟังก์ชัน RenderScene ใหม่อีกครั้ง |
| `glutTimerFunc(msec, callback, val)` | ตั้งเวลาในการเรียกใช้งานฟังก์ชัน callback หนึ่งครั้งหลังจากผ่านไป msec มิลลิวินาที |
