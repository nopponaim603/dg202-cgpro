## 🏛️ ทฤษฎีและเนื้อหาหลัก

### 1. ระบบดักจับการกดปุ่มบนคีย์บอร์ด (Keyboard Events)
* **Normal Keys (`glutKeyboardFunc`)**: จัดการปุ่มอักขระ ASCII ทั่วไป (ตัวพิมพ์เล็ก-ใหญ่มีผลต่างกัน) รวมถึงปุ่ม Enter, Spacebar, Escape (ค่ารหัส ASCII 27)
* **Special Keys (`glutSpecialFunc`)**: จัดการปุ่มที่ไม่สามารถแปลงเป็นรหัส ASCII แบบอักษรเดี่ยวปกติได้โดยง่าย เช่น:
  * ปุ่มลูกศรทิศทาง (`GLUT_KEY_UP`, `GLUT_KEY_DOWN`, `GLUT_KEY_LEFT`, `GLUT_KEY_RIGHT`)
  * ปุ่มฟังก์ชัน F1 ถึง F12 (`GLUT_KEY_F1` ฯลฯ)
  * ปุ่ม Page Up/Down, Home, End

### 2. การควบคุมและติดตามพิกัดเมาส์ (Mouse Events)
* **Mouse Clicks (`glutMouseFunc`)**: รับรู้เมื่อเกิดเหตุการณ์กดคลิกลงหรือยกขึ้นของเมาส์ซ้าย เมาส์กลาง และเมาส์ขวา
* **Active Motion (`glutMotionFunc`)**: เรียกทำงานอย่างต่อเนื่องเมื่อผู้ใช้งาน **ลากเมาส์ขยับไปมาในขณะที่กดปุ่มเมาส์ใดปุ่มหนึ่งค้างไว้**
* **Passive Motion (`glutPassiveMotionFunc`)**: เรียกทำงานเมื่อผู้ใช้งาน **เลื่อนเมาส์เคลื่อนที่ผ่านหน้าต่างโปรแกรมธรรมดา** โดยไม่ได้กดคลิกเมาส์เลย

## 💻 ฟังก์ชันสำคัญและการประยุกต์ใช้งาน

### 1. การดักจับปุ่มร่วมกับปุ่มคำสั่งหลัก (Modifiers)
ใน Callback คีย์บอร์ดหรือเมาส์ เราสามารถตรวจสอบได้ว่าผู้ใช้กำลังกดปุ่ม Shift, Ctrl หรือ Alt ค้างไว้ด้วยหรือไม่ผ่าน **`glutGetModifiers()`**:
```cpp
void processMouse(int button, int state, int x, int y) {
    // ตรวจสอบว่าเป็นการกดปุ่มคลิกเมาส์ซ้าย และมีการกดปุ่ม ALT ค้างไว้ด้วยหรือไม่
    if (button == GLUT_LEFT_BUTTON && state == GLUT_DOWN) {
        if (glutGetModifiers() == GLUT_ACTIVE_ALT) {
            // ดำเนินการ เช่น เปลี่ยนสีวัตถุเป็นสีแดง
            red = 1.0f; green = 0.0f; blue = 0.0f;
        }
    }
}
```

### 2. การแปลงตำแหน่งเมาส์เป็นพิกัดการหมุนโมเดล (Lab6_2)
เราสามารถนำพิกัดพิกเซลเมาส์ $(x, y)$ บนหน้าต่างความละเอียดกว้างขวาง $800 \times 800$ มาสเกลสัดส่วนให้เป็นทรานส์ฟอร์มองศาหมุนโมเดล $0^\circ \text{ ถึง } 180^\circ$ ได้ดังนี้:
```cpp
void processMousePassiveMotion(int x, int y) {
    // จำกัดขอบเขตพิกัด x ให้อยู่ในช่วง 0 ถึง 800
    if (x < 0) x = 0;
    else if (x > 800) x = 800;
    
    // แปลงพิกัด x เป็นองศาการหมุนแกน X (สเกลสูงสุด 180 องศา)
    angleX = 180.0f * ((float)x) / 800.0f;
    glutPostRedisplay(); // ร้องขอให้วาดเฟรมใหม่
}
```
