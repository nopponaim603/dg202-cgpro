## 🏛️ ทฤษฎีและเนื้อหาหลัก

### 1. องค์ประกอบการสะท้อนแสง (Reflection Model)
OpenGL คำนวณความสว่างของวัตถุโดยใช้แสงสะท้อนรวมกัน 3 ส่วน:
1. **Ambient Light (แสงแวดล้อม)**: แสงตกกระทบที่กระจายฟุ้งอยู่ในฉากอย่างทั่วถึง ไม่มีทิศทางเด่นชัด ทำให้เห็นรายละเอียดในเงามืด
2. **Diffuse Light (แสงสะท้อนพร่า)**: แสงที่สะท้อนจากผิวขรุขระเล็กระดับนาโน สว่างจ้าที่สุดเมื่อหน้าวัตถุหันเข้าหาตำแหน่งของแสงตามมุมตกกระทบ (สอดคล้องกับกฎโคไซน์ของแลมเบิร์ต)
3. **Specular Light (แสงสะท้อนมันวาว)**: แสงที่ชี้เฉพาะสะท้อนเข้าสู่มุมมองของผู้สังเกตตรง ๆ เกิดจุดไฮไลท์เรืองแสงสว่างแวววาว (จุด Highlight บนผิวกระจกหรือโลหะที่สะท้อนจุดแสง) ความกว้างของจุดจะบีบตัวให้เล็กและสว่างคมชัดขึ้นเมื่อกำหนดตัวแปร **Shininess** สูง

### 2. โมเดลการคำนวณวัสดุผสมสีปัจจุบัน (Color Material)
ปกติเมื่อเปิดระบบแสง `glEnable(GL_LIGHTING)` คำสั่งระบุสีธรรมดาอย่าง `glColor*()` จะไม่มีผลใดๆ เนื่องจากโปรแกรมจะหันไปใช้ค่าสัมประสิทธิ์วัสดุของ `glMaterial*()` แทน แต่เราสามารถสั่งให้ค่าสีของจุดยอดกลับมาทำงานร่วมกับแสงได้โดย:
* **`glEnable(GL_COLOR_MATERIAL)`**: สั่งให้สีปัจจุบันผูกมัดเป็นค่าสัมประสิทธิ์ของวัสดุตัวนั้นไปพร้อมกัน ทำให้แก้ไขโทนสีวัตถุตามจุดยอดต่าง ๆ ได้ง่ายขึ้น

## 💻 ฟังก์ชันสำคัญและการประยุกต์ใช้งาน

### 1. ตั้งค่าคุณสมบัติแหล่งกำเนิดแสง (Light Configuration)
```cpp
float light_pos[] = { 10.0f, 10.0f, 20.0f, 1.0f }; // กำหนดตำแหน่งแกน X, Y, Z (1.0f ท้ายสุดชี้เป็นจุดแสงสปอตไลท์ตำแหน่งสัมบูรณ์)
float light_diffuse[] = { 1.0f, 1.0f, 1.0f, 1.0f }; // แสงสีขาวส่องสว่างวัตถุ

glLightfv(GL_LIGHT0, GL_POSITION, light_pos);
glLightfv(GL_LIGHT0, GL_DIFFUSE, light_diffuse);
glEnable(GL_LIGHTING); // เปิดระบบประมวลผลแสง
glEnable(GL_LIGHT0);   // เปิดสวิตช์แหล่งกำเนิดแสงดวงที่ 0
```

### 2. การกำหนดสมบัติทางวัสดุเฉพาะตัว (Material Settings)
ตัวอย่างการใส่ค่าวัสดุ "ทองคำ (Gold)" จากตารางการจำลอง:
```cpp
float mat_ambient[] = { 0.24725f, 0.1995f, 0.0745f, 1.0f };
float mat_diffuse[] = { 0.75164f, 0.60648f, 0.22648f, 1.0f };
float mat_specular[] = { 0.628281f, 0.555802f, 0.366065f, 1.0f };
float mat_shininess = 51.2f; // ระดับเงาวาว (0 ถึง 128)

glMaterialfv(GL_FRONT, GL_AMBIENT, mat_ambient);
glMaterialfv(GL_FRONT, GL_DIFFUSE, mat_diffuse);
glMaterialfv(GL_FRONT, GL_SPECULAR, mat_specular);
glMaterialf(GL_FRONT, GL_SHININESS, mat_shininess);

glutSolidTeapot(10.0); // วาดกาน้ำชาสีทองคำสะท้อนแสงอย่างเงางาม
```
