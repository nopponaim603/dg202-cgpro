## 🏛️ ทฤษฎีและเนื้อหาหลัก

### 1. การผสมสีโปร่งแสง (Alpha Blending)
ในการวาดวัตถุใสหรือกระจกแสงผ่าน OpenGL จะคำนวณการรวมสีของพิกเซลที่วาดทับลงบนบัฟเฟอร์เดิม:
* **Source Color (สีต้นทาง)**: ค่าสีของวัตถุใหม่ที่กำลังจะถูกเรนเดอร์ในจุดเดียวกัน
* **Destination Color (สีปลายทาง)**: สีที่มีการแสดงผลค้างอยู่บนเฟรมบัฟเฟอร์ในปัจจุบัน
* การคำนวณน้ำหนักการผสมคุมผ่านพารามิเตอร์ **Alpha ($a$)** ที่มีสเกลค่า $[0.0, 1.0]$:
  * $a = 1.0$: ทึบแสงสมบูรณ์ แสดงเฉพาะสีต้นทางใหม่
  * $a = 0.0$: โปร่งใสสมบูรณ์ สีต้นทางจะไม่ไปเปลี่ยนภาพบัฟเฟอร์เดิม
  * $a = 0.5$: กึ่งโปร่งใส ผสมสีของทั้งสองแบบเท่า ๆ กัน
* **`glBlendFunc(sfactor, dfactor)`**: ใช้ระบุฟังก์ชันสัมประสิทธิ์การคูณสัดส่วนสีผสม

### 2. เอฟเฟกต์จำลองม่านหมอก (Fog Simulation)
หมอกช่วยสร้างมิติความลึกในพื้นที่ห่างไกล โดยคำนวณผสมสีหมอกกับสีวัตถุตามระยะห่างของแกน Z จากตัวกล้อง:
* **โหมดการลดระดับความคมชัด (Fog Modes)**:
  * **`GL_LINEAR`**: หมอกจะหนาขึ้นแบบเป็นเส้นตรงเชิงเดี่ยว คุมตามช่วงระยะเริ่มต้นถึงระยะตัดท้าย (`GL_FOG_START` และ `GL_FOG_END`)
  * **`GL_EXP`**: หมอกจะสะสมหนาตัวขึ้นตามฟังก์ชันเอกซ์โพเนนเชียลธรรมชาติ $e^{-d \cdot z}$ คุมด้วยค่าความหนาแน่น `GL_FOG_DENSITY`
  * **`GL_EXP2`**: หมอกหนาตัวอย่างรวดเร็วเป็นสองเท่าตามการกระจายตัวแบบระฆังคว่ำ $e^{-(d \cdot z)^2}$

## 💻 ฟังก์ชันสำคัญและการประยุกต์ใช้งาน

### 1. การเรนเดอร์ภาพผสมสีโปร่งแสง (Lab8_1)
```cpp
glEnable(GL_BLEND); // 1. เปิดระบบประสมสี
glBlendFunc(GL_SRC_ALPHA, GL_ONE); // 2. ระบุสัมประสิทธิ์การคูณน้ำหนัก (เรืองแสงสว่างทับซ้อน)

// 3. วาดวัตถุกึ่งโปร่งใส (มีแชนแนล Alpha น้อยกว่า 1.0)
glColor4f(1.0f, 0.0f, 0.0f, 0.5f); // สีแดงโปร่งแสง 50%
glBegin(GL_TRIANGLES);
    glVertex3f(5.0f, 0.0f, 5.0f);
    glVertex3f(15.0f, 0.0f, 5.0f);
    glVertex3f(10.0f, 15.0f, 10.0f);
glEnd();

glDisable(GL_BLEND); // ปิดการประสมเมื่อเรนเดอร์เสร็จสิ้น
```

### 2. การสร้างและกำหนดค่าหมอก (Lab8_2)
```cpp
float fog_colour[] = { 0.6f, 0.58f, 0.79f, 0.0f }; // สีม่วงอมเทา
float fog_density = 0.05f;

// ตั้งค่าล้างหน้าจอด้วยสีเดียวกับหมอกเพื่อเอฟเฟกต์ที่เนียนตา
glClearColor(fog_colour[0], fog_colour[1], fog_colour[2], fog_colour[3]);

glEnable(GL_FOG); // เปิดระบบแสดงผลหมอก
glFogfv(GL_FOG_COLOR, fog_colour); // โทนสีของหมอก
glFogi(GL_FOG_MODE, GL_EXP);       // ใช้สูตรลดทอนแบบ Exponential
glFogf(GL_FOG_DENSITY, fog_density); // ระบุความเข้มข้นของละอองหมอก
glFogf(GL_FOG_START, 0.05f);       // ระยะเริ่มต้นเกิดหมอกจางๆ
glFogf(GL_FOG_END, 200.0f);        // ระยะสิ้นสุดภาพที่กลืนหายไปในหมอก
```
