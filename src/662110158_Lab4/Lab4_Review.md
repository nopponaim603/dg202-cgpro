## 🏛️ ทฤษฎีและเนื้อหาหลัก

### 1. ฟิสิกส์ของแสงและการรับรู้สี (Physics of Color)
* สายตาของมนุษย์รับรู้สีผ่านเซลล์รูปกรวยบนเรตินา ซึ่งตอบสนองต่อช่วงคลื่นแสงหลัก 3 ช่วง: แดง (Red), เขียว (Green), และน้ำเงิน (Blue)
* การเกิดสีในคอมพิวเตอร์กราฟิกใช้ **Additive Color Mixing** (การผสมสีแบบบวกแสง) โดยการผสมผสานสัดส่วนกระตุ้นของแม่สีบวกแสงทั้ง 3 สีเข้าด้วยกัน
* ตัวอย่างเช่น โฟตอนแสงสีแดง 6 หน่วย ผสมกับสีเขียว 4 หน่วย และสีน้ำเงิน 1 หน่วย จะส่งภาพเข้าสู่สมองเพื่อประมวลผลเป็น "สีน้ำตาล"

### 2. รูปแบบการจัดแสงเงาและการระบายสี (Shading Models)
* **Flat Shading (`glShadeModel(GL_FLAT)`)**:
  * ใช้ค่าสีของจุดยอดพิกเซลจุดเดียว (ปกติเป็นจุดสุดท้ายของประเภครูปเหลี่ยมนั้น) ในการทาสีระนาบทั้งหมดของ Face นั้น ๆ
  * ผลลัพธ์ที่ได้จะเป็นแผ่นสีเหลี่ยมขอบคมตัดกันชัดเจน
* **Smooth Shading (`glShadeModel(GL_SMOOTH)`)**:
  * เรียกอีกชื่อหนึ่งว่า **Gouraud Shading**
  * ระบบจะคำนวณเฉลี่ยค่าสีจากพิกัดจุดยอด (Vertices) ของหน้าตัด แล้วใช้วิธี **Color Interpolation** (การแทรกเฉลี่ยเชิงเส้น) ในการไล่โทนสีตามตำแหน่งจุดตัดขวางไปทั่วผิวสัมผัสแบบกลมกลืน

## 💻 ฟังก์ชันสำคัญและการประยุกต์ใช้งาน

### 1. การกำหนดสี
* **`glColor3f(r, g, b)`**: กำหนดแม่สีด้วยค่าเลขทศนิยมลอยตัวระบุสเกล $[0.0, 1.0]$
* **`glColor3ub(r, g, b)`**: กำหนดแม่สีด้วยค่าจำนวนเต็มชนิดไม่มีเครื่องหมายระบุสเกล $[0, 255]$

### 2. การสร้างกล่อง RGB Cube ไล่เฉดสีนุ่มนวล (Lab4_1)
กำหนดสีที่แตกต่างกันให้กับจุดยอดแต่ละมุมของลูกบาศก์ เพื่อให้ระนาบเกลี่ยสีเข้าหากัน:
```cpp
glShadeModel(GL_SMOOTH); // เปิดใช้งานการไล่ระดับเฉดสี

glBegin(GL_QUADS);
    // หน้าที่ 1 (วาดด้านหน้า)
    glColor3f(1.0f, 0.0f, 0.0f); glVertex3f(-15.0f, -15.0f, 15.0f); // แดง (ล่างซ้าย)
    glColor3f(0.0f, 1.0f, 0.0f); glVertex3f(15.0f, -15.0f, 15.0f);  // เขียว (ล่างขวา)
    glColor3f(0.0f, 0.0f, 1.0f); glVertex3f(15.0f, 15.0f, 15.0f);   // น้ำเงิน (บนขวา)
    glColor3f(1.0f, 1.0f, 1.0f); glVertex3f(-15.0f, 15.0f, 15.0f);  // ขาว (บนซ้าย)
glEnd();
```
* **ผลลัพธ์**: จะพบการไล่ระดับสีแดงแผ่กระจายไปหาเขียว น้ำเงิน และขาวอย่างนุ่มนวลไร้รอยต่อบนผิวกล่อง
