## 🏛️ ทฤษฎีและเนื้อหาหลัก

### 1. Bitmaps vs. Pixelmaps (ความแตกต่างที่สำคัญ)
* **Bitmap (`glBitmap`)**:
  * ข้อมูลพิกเซลแต่ละตัวใช้พื้นที่บันทึกเพียง **1 บิต** (0 หรือ 1 เท่านั้น) ทำหน้าที่เสมือนแผ่นปิดกรอง (Mask)
  * หากพิกัดบิตเป็น `1` ระบบจะเรนเดอร์พิกเซลนั้นด้วย **สีปัจจุบันที่เลือกใช้** (Current Color) หากบิตเป็น `0` จะข้ามพิกเซลนั้นไปโดยไม่ทำอะไร
  * นิยมนำไปใช้ทำแบบฟอนต์ตัวอักษร 2D หรือภาพสัญลักษณ์ขนาดเล็กในหน้าจออินเตอร์เฟซ
* **Pixelmap / Pixmap (`glDrawPixels`)**:
  * พิกเซลแต่ละตัวจะเก็บค่าสีของตัวเองแยกย่อยออกมาโดยตรง (เช่น เก็บเป็นสี RGB ขนาด 3 ไบต์ หรือ RGBA ขนาด 4 ไบต์)
  * ภาพวาดจะรักษาโทนสีและเฉดสีจริงตามที่อยู่ในหน่วยความจำอาร์เรย์ ไม่ขึ้นกับสีปัจจุบันของตัวเขียน

### 2. การจัดการตำแหน่งวาดบนจอภาพแรสเตอร์ (Raster Position)
เนื่องจากเราวาดพิกเซลตรงหน้าจอ 2D ระนาบแรสเตอร์ ไม่ใช่พิกัดพิกเซลเวกเตอร์ในโลก 3D จึงจำเป็นต้องระบุตำแหน่งเริ่มเขียนพิกเซลพิกัดจอด้วย:
* **`glRasterPos2i(x, y)`**: สั่งเลื่อนพิกัดปากกาเขียนจุดภาพแรสเตอร์ไปที่แกน $[x, y]$

## 💻 ฟังก์ชันสำคัญและการประยุกต์ใช้งาน

### 1. การวาดรูปสัญลักษณ์ด้วยบิตแมป (Lab7_1)
ตัวอย่างการเตรียมอาร์เรย์ 1 บิตเพื่อร่างลายเครื่องหมายกากบาทขนาดเล็ก:
```cpp
// กำหนดแพทเทิร์นขนาดยม 16x16 พิกเซล
GLubyte crossPattern[] = {
    0x01, 0x80, // 00000001 10000000
    0x02, 0x40, // 00000010 01000000
    0x04, 0x20, // 00000100 00100000
    0x08, 0x10, // 00001000 00010000
    0x10, 0x08, // 00010000 00001000
    0x20, 0x04, // 00100000 00000100
    0x40, 0x02, // 01000000 00000010
    0x80, 0x01  // 10000000 00000001
};

// เคลื่อนย้ายตำแหน่งและวาดบิตแมป
glRasterPos2i(100, 100);
glColor3f(1.0f, 0.0f, 0.0f); // วาดกากบาทด้วยสีแดง
glBitmap(16, 8, 0.0, 0.0, 0.0, 0.0, crossPattern);
```

### 2. การสร้างภาพตารางหมากรุกผ่าน Pixelmap (Lab7_2)
สร้างอาร์เรย์สี RGB ขนาด $256 \times 256$ พิกเซล แล้ววาดลงจอโดยใช้ `glDrawPixels`:
```cpp
GLubyte checkBoard[256][256][3]; // อาร์เรย์เก็บสี RGB

// สร้างแพทเทิร์นตารางหมากรุกผ่านลอจิกบิต XOR
for (int i = 0; i < 256; i++) {
    for (int j = 0; j < 256; j++) {
        int c = ((((i & 0x8) == 0) ^ ((j & 0x8)) == 0)) * 255;
        checkBoard[i][j][0] = (GLubyte)c; // แชนแนล R
        checkBoard[i][j][1] = (GLubyte)c; // แชนแนล G
        checkBoard[i][j][2] = (GLubyte)c; // แชนแนล B
    }
}

// ลงทะเบียนการจัดแถวข้อมูลและนำไปเรนเดอร์
glPixelStorei(GL_UNPACK_ALIGNMENT, 1);
glRasterPos2i(10, 10);
glDrawPixels(256, 256, GL_RGB, GL_UNSIGNED_BYTE, checkBoard);
```
